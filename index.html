Cinq façons d'assortir vos couleurs

Chaque mode suit une règle de la théorie des couleurs. Cliquez sur un mode pour l'essayer.

Comment ça marche

  1. 1

    Choisissez un mode

    Analogue pour de la douceur, complémentaire pour du contraste, monochrome pour la sobriété.

  2. 2

    Appuyez sur Espace

    Une nouvelle palette à chaque appui. Les couleurs proches sont toujours rangées côte à côte.

  3. 3

    Verrouillez et copiez

    Le cadenas garde une couleur. Un clic copie son code, un bouton exporte toute la palette en CSS.

Tout ce qu'il faut, rien de plus

🔒 Verrouillage

Gardez les couleurs qui vous plaisent pendant que les autres changent.

🌈 Tri par teinte

Les verts restent avec les verts : la palette se lit naturellement.

🏷️ Noms de couleurs

Chaque couleur reçoit un nom (Corail, Bleu nuit…) que vous pouvez renommer.

✎ Palette sur mesure

Ajoutez, supprimez ou modifiez les couleurs, de 2 à 10 par palette.

📋 Copie en un clic

Cliquez sur une couleur pour copier son code hexadécimal.

🎨 Export CSS

Toute la palette en variables nommées (--corail, --bleu-nuit…), prête à coller.

🖼️ Export image

Téléchargez la palette en PNG, avec les noms et les codes.

🔗 Partage par lien

Les couleurs sont dans l'adresse : envoyez le lien, on voit la même palette.
